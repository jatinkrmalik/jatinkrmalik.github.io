I'm Jatin. I've been writing code for close to 20 years, and doing it for a living since 2014.

These days I'm a Principal Engineer at Atlassian and the architect of the agentic interfaces platform in the AI Integrations org, which builds Atlassian's agentic surface: MCP, A2A, CLI, MCP apps and A2UI. Before that I worked on data residency with the Enterprise Trust team, and before Atlassian I was at Uber, Synaptic, Shuttl, Adobe and Webyog.

I grew up in Delhi, lived in Bangalore, moved to Chicago in 2024 and have been in the San Francisco Bay Area since September 2025.

How it started

It started when I was about five, watching my uncle boot a freshly assembled Pentium II into Windows 95. I got my own PC in 8th grade after a deal with my dad to score over 90% (I mostly wanted it for games), and I broke it more than once by deleting files from C:\Windows\System32. A Digit magazine DVD gave me Microsoft FrontPage and my first HTML pages, and a borrowed copy of Let Us C++ had me printing primes and digits of pi.

In school I scored almost full marks in C and C++ while barely passing the other sciences. I didn't clear IIT-JEE and did my B.Tech in Computer Science from GGSIPU in Delhi, where I built Windows Phone apps as a Microsoft Student Partner. I started my career with an internship at a startup, but my open-source contributions soon got me invited to interview at Adobe. I used to contribute to Brackets, Adobe's open-source code editor, and I was a huge fan of it back then.

Why this blog

I've been writing online for almost as long as I've been coding. It started with TechSalvos, a gadget news blog I ran in college, then The JavaScript Journey, BitSnapper, an engineering blog on GitHub Pages, Medium, LinkedIn, X and DEV. Every one of them lived on a different platform, and a few are gone now. This blog is my step to consolidate all of it in one place: everything worth keeping is recovered and moved here, and anything new gets published here first.

So you'll find a bit of everything: distributed systems, the open-source tools I build for myself like Vocalinux, homelab builds, teardowns, Advent of Code, and the old BitSnapper gadget reviews and motorcycle diaries.

Open source

  • Vocalinux 1k

    Free, open-source and fully offline voice dictation for Linux. Speak and it types anywhere, on X11 and Wayland, using whisper.cpp, Whisper or VOSK, with GPU acceleration.

    Python · 2025 GitHub Demo Read the post

  • LLMFeeder 488

    A browser extension that turns any web page into clean Markdown and copies it to your clipboard, so you can hand it to an LLM as context in one click.

    JavaScript · 2025 GitHub Demo

  • VocaMac 164

    Open-source, offline voice-to-text for macOS. Hold a hotkey, speak, and the text appears. Private on-device dictation with a choice of speech engines.

    Swift · 2026 GitHub

  • VocaWin 64

    The same idea for Windows, in beta: hold a hotkey, speak, and the text appears, using local Whisper and ONNX models on your own machine.

    Rust · 2026 GitHub

    Swift · 2026 GitHub
