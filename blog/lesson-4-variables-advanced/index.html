Now, let’s look up the explanation of All types of Variables one by one:

  1. Integer (INT): As the name suggests, It is used to store the value of an Integer number (like 12,4,6..).
  2. Float: It is also used to store a Number but with Decimal structure (like 0.02, 0.6, 13.5..).
  3. String: A string is a variable which stores a series of characters like “John Doe”. Strings are written with quotes.
  4. Boolean: Booleans can only have two values: true or false. They are generally used as Flags/Switch.
  5. Null: The value of a variable with no value is undefined. Variables can be emptied by setting the value to null. Note: Null is not equal to Zero (0).

So, here we go. This lesson was to make you understand different types of Variables and how to use them.
