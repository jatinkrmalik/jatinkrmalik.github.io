A tiered guide to routing OpenCode Go models across oh-my-openagent agents, with fallback chains and budgeting to avoid hitting rate and monthly limits.

The Problem: The $15 Cap Is the New Trap

OpenCode Go limits are still dollar-based. The 5-hour / weekly / monthly windows are 20% / 50% / 100% of each model’s monthly dollar cap, not a shared $12 / $30 / $60 for every model:

  • $60 monthly models (GLM-5.2, MiniMax M3, MiMo-V2.5, GLM-5.3-Flash): $12 / 5hr, $30 weekly, $60 monthly
  • $30 monthly (V4 Flash, Qwen3.8 Flash, Qwen3.7 Max, Hy4): $6 / 5hr, $15 weekly
  • $15 monthly (K3, GLM-5.3, Grok 4.6, Luna, Qwen3.8 Max, V4 Pro, V4.1 Flash, MiMo-V2.5-Pro): $3 / 5hr, $7.50 weekly

A single agentic coding session burns 50–200 requests (one per tool call, file edit, shell command). Put the orchestrator on Kimi K3 (110 req/5hr) or GLM-5.3 (220 req/5hr) and you’ll hit the wall in one serious session.

Luna is the one that fools people. It still shows 2,050 req/5hr. V4.1 Flash shows 6,500. Those look like volume. They’re $15/month. Luna can empty the month in one fat window. V4 Pro dropped from 3,450 req/5hr in August to 1,050, same $15 cap.

If you put Sisyphus on Qwen3.8 Max “because 67.7% SWE-Pro,” you’ll also fight oh-my-openagent’s own guidance. Qwen is fine for many worker roles. It is not a maintained Sisyphus brain. OmO’s Capable profile is Claude Fable 5.1 → Claude Opus 5 → Kimi K3 → GLM-5.3. Qwen isn’t on that list.

The fix: tiered routing + deep fallback_models chains, with orchestrators from the OmO-supported set. Treat every $15 model as scarce even when the 5-hour column looks fat.

Step 1: Install OpenCode + Oh My Open Agent

Prerequisites

  • OpenCode 1.4.0+ (verify with opencode --version)
  • Git, Node.js or Bun
  • macOS, Linux, or WSL

Install OpenCode

curl -fsSL https://opencode.ai/install | bash
opencode --version

Install Oh My Open Agent

bunx oh-my-opencode install

For non-interactive setup (LLM agents, CI):

bunx oh-my-opencode install --no-tui \
  --opencode-go=yes \
  --opencode-zen=yes \
  --claude=no \
  --openai=no \
  --gemini=no \
  --copilot=no

FYI, OmO’s better stack is still OpenCode Go ($10) + a real OpenAI path if Hephaestus / deep / ultrabrain are daily drivers. The Deep work profile leads with GPT-6 Astra, then GPT-5.6 Sol. Luna is on Go, but it’s $15/month, so treat it as a burst.

Pure Go is fine for Sisyphus / Atlas / Oracle / Explore / Librarian if you keep Sisyphus on GLM-5.2.

Verify Installation

opencode --version              # Should be 1.4.0+
bunx oh-my-opencode doctor      # Diagnostics check
opencode models                 # List available models
opencode auth login             # Authenticate providers

In the TUI: /connect → OpenCode Go → paste key, then /models.

The core principle: match model capability (and family fit) to task complexity. Don’t burn your best model on trivial tasks!

FYI, numbering is top to bottom Tier 0 → 1 → 2 → 3 (scarce → complex → standard → volume). Escalate up if stuck. Tier 4 stays specialized.

Step 4: Configure Rate Limit Resilience

Enable model_fallback and set up fallback chains so rate limits don’t break your workflow:

{
  "model_fallback": true,
  "runtime_fallback": {
    "enabled": true,
    "retry_on_errors": [400, 429, 503, 529],
    "max_fallback_attempts": 3,
    "cooldown_seconds": 60,
    "timeout_seconds": 30,
    "notify_on_fallback": true
  }
}

When a provider hits rate limits, it’s globally blacklisted for cooldown_seconds. All new sessions skip blacklisted providers until cooldown expires.

429 on GLM-5.2 → Kimi K2.7 Code → GLM-5.3-Flash

FYI, if you also have Zen credits, enable Use balance in the console. Go can then use Zen balance after dollar limits instead of hard-blocking.

Step 7: The Quality Trade-Offs

Without Copilot / Claude Max / OpenAI Sol, you’re on a pure OpenCode Go stack. Stronger than August (GLM-5.3, Grok 4.6, Qwen3.8 Max). Also easier to empty, because several of those sit on $15 monthly caps.

Where You Win ✔

  • Cost: $10/month vs $50–200 in stacked Anthropic + OpenAI API bills
  • Model diversity: 27 Go models, up from 17 in August
  • SWE-Bench Verified: Grok 4.6 (95.6%), GLM-5.3 (95.4%), V4 Pro 0813 (96.4%) sit next to Opus 5 (97.0%) and Sol (~96%)
  • SWE-Bench Pro vs OpenAI: Qwen3.8 Max (67.7%) beats Sol (64.6%) on the published Pro board. Luna (62.7%) and GLM-5.2 (62.1%) sit with Terra (63.4%)
  • Orchestration: Kimi K3 / GLM-5.3 / GLM-5.2 are OmO-supported Sisyphus brains. 5.2 has the $60 cap
  • LiveCodeBench: V4 Pro still leads (~93.5%). Use it as a burst
  • Rate limits: MiMo-V2.5 (30,100, $60) for search. GLM-5.3-Flash (6,320, $60) for volume GLM
  • Zen balance fallback: optional soft landing after dollar limits

Where You Compromise !?

  • Anthropic Pro gap: Fable 5.1 / Mythos / Fable / Opus sit at 79–81% SWE-Pro. Best Go score is 67.7% and 160 req/5hr
  • $15 models with fat 5-hour numbers: Luna, V4 Pro, V4.1 Flash, MiMo-V2.5-Pro. August daily-driver configs will empty the month
  • Hephaestus without Astra/Sol: MiniMax M3 is the honest Go daily. OmO still prefers GPT-6 Astra / GPT-5.6 Sol
  • Qwen-as-orchestrator temptation: 67.7% SWE-Pro ≠ Sisyphus fit. Resist it
  • Privacy: Grok 4.6 and Luna retain data 30 days. Muse Spark Contributor trains on prompts. Most open models list 0-day retention. DeepSeek ZDR on Go is valid through September 30, 2026, renewed monthly

Verdict: Against Sol/Terra, Go looks excellent for the money. Against Fable 5.1, expect more iterations on the hardest architecture work.

For most day-to-day coding, a GLM-5.2-led Go stack with MiniMax M3 / GLM-5.3-Flash / MiMo-V2.5 underneath is the right default. Add OpenAI Astra/Sol if Hephaestus is a daily driver. Add Claude only if you need that top SWE-Pro band.

Key Principles (September 2026)

  1. Don’t route everything through one model. $15 models are scarce. GLM-5.2 is the sustainable orchestrator. MiMo-V2.5 / GLM-5.3-Flash take volume.
  2. Read the monthly column, not just req/5hr. Luna at 2,050 looks like a daily driver. It’s $15/month.
  3. Don’t put Qwen/MiniMax/DeepSeek/MiMo on Sisyphus. OmO maintainers explicitly warn against it.
  4. Don’t “upgrade” utility agents. Explore/Librarian want MiMo-V2.5, not K3.
  5. Use fallback_models everywhere. Chains should be 3-4 deep, with a $60 model at the bottom.
  6. Keep concurrency conservative on $15 models. Start at 1–2 parallel tasks.
  7. GLM-5.2 is your default Sisyphus/Oracle on Go. GLM-5.3 is ultrawork. Grok 4.6 is scarce frontier. MiniMax M3 is daily Hephaestus.
