The almanac starts by listing which seeds need to be planted: seeds 79, 14, 55, and 13.

The rest of the almanac contains a list of maps which describe how to convert numbers from a source category into numbers in a destination category. That is, the section that starts with seed-to-soil map: describes how to convert a seed number (the source) to a soil number (the destination). This lets the gardener and his team know which soil to use with which seeds, which water to use with which fertilizer, and so on.

Rather than list every source number and its corresponding destination number one by one, the maps describe entire ranges of numbers that can be converted. Each line within a map contains three numbers: the destination range start, the source range start, and the range length.

Consider again the example seed-to-soil map:

50 98 2
52 50 48

The first line has a destination range start of 50, a source range start of 98, and a range length of 2. This line means that the source range starts at 98 and contains two values: 98 and 99. The destination range is the same length, but it starts at 50, so its two values are 50 and 51. With this information, you know that seed number 98 corresponds to soil number 50 and that seed number 99 corresponds to soil number 51.

The second line means that the source range starts at 50 and contains 48values: 50, 51, …, 96, 97. This corresponds to a destination range starting at 52 and also containing 48 values: 52, 53, …, 98, 99. So, seed number 53 corresponds to soil number 55.

Any source numbers that aren’t mapped correspond to the same destination number. So, seed number 10 corresponds to soil number 10.

So, the entire list of seed numbers and their corresponding soil numbers looks like this:

The gardener and his team want to get started as soon as possible, so they’d like to know the closest location that needs a seed. Using these maps, find the lowest location number that corresponds to any of the initial seeds. To do this, you’ll need to convert each seed number through other categories until you can find its corresponding location number. In this example, the corresponding types are:

So, the lowest location number in this example is 35.

What is the lowest location number that corresponds to any of the initial seed numbers?

💡 We don’t really need to worry about any source numbers that aren’t mapped, as we can just assume source == destination which becomes quite trivial in python with dict.get(key, default_value) where default value will just be the key itself.

So, I was able to write a simple loop which will basically call each and every map chained to one another and will store the final location in seed_location_map and from there we could just return min(seed_location_map.values()) for the answers.

💡 Edge case: We need to ensure that we maintain the order of maps as we are parsing the input, as if we mess up the order, the pipe | approach as we discussed above wouldn’t work. I am using a collections.deque object to ensure we reach from seed to the seed-to-soil > soil-to-fertilizer > fertilizer-to-water > water-to-light > light-to-temperature > temperature-to-humidity > humidity-to-location location.

from collections import deque

def dict_builder(raw_map):
    raw_map = raw_map.strip("\n")
    dict_name, mappings = raw_map.split(':')
    dict_name = dict_name.split()[0]
    mappings = mappings.strip("\n").split("\n")

    dict_data = {}

    for row in mappings:
        dest, src, range_length = [int(num) for num in row.split()]
        for i in range(range_length):
            dict_data[src+i] = dest+i
    
    return dict_name, dict_data

def find_lowest_location_number(almanac):
    almanac = almanac.split("\n\n")

    # extract out seeds? assuming it's always first in the puzzle input
    seeds = [int(seed) for seed in almanac[0].split(":")[1].strip().split(" ")] 

    queue_of_dicts = deque() 

    for raw_map in almanac[1:]:
        tmp_name, tmp_data = dict_builder(raw_map)
        queue_of_dicts.append((tmp_name, tmp_data))

    # print(queue_of_dicts)

    seed_location_map = {}
    for seed in seeds:
        final_val = seed
        for _, tmp_map in queue_of_dicts:
            final_val = tmp_map.get(final_val, final_val) # update if found, else keep it same as key
        
        seed_location_map[seed]=final_val

    print("Seed location map:", seed_location_map)
    return min(seed_location_map.values())

💡 Instead of creating a complete mapping for each step, we can write a function that, given a number and a map range, computes the corresponding number dynamically. This way, we avoid holding large maps in memory!

In this updated code, find_mapped_number function dynamically calculates the mapped number for a given input number and a single mapping range.

It works by iterating through a list of mapping rules and, for each rule, checks if the given number falls within the specified source range. If it does, the function calculates the mapped number by adding the difference between the given number and the source range start to the destination range start.

This function is used within find_lowest_location_number to process each seed number through the series of mappings without storing the entire range of mappings in memory. This should resolve the memory issue and allow the program to handle large input data efficiently 🤞

# --- Day 5: If You Give A Seed A Fertilizer ---

class AlmanacProcessor:
    def __init__(self, almanac):
        self.almanac = almanac
        self.seeds, self.mappings = self._parse_input(almanac)

    def find_lowest_location_number(self):
        """Finds the lowest location number based on the almanac's rules."""
        seed_locations = {}
        for seed in self.seeds:
            current_number = seed
            for map_data in self.mappings:
                current_number = self._find_mapped_number(current_number, map_data)
            seed_locations[seed] = current_number  # location of seed in last map
        return min(seed_locations.values())

    def _parse_input(self, input_data):
        """Parses the input data into seeds and mappings."""
        sections = input_data.strip().split('\n\n')
        seeds = list(map(int, sections[0].split(': ')[1].split()))
        mappings = [section.split(':\n')[1].split('\n') for section in sections[1:]]
        return seeds, mappings

    def _find_mapped_number(self, number, map_data):
        """Finds the corresponding mapped number based on the mapping rules."""
        for line in map_data:
            if line.strip():
                dest_start, src_start, length = map(int, line.split())
                if src_start <= number < src_start + length:
                    return dest_start + (number - src_start)
        return number

💡 The essence of part 2 solution lies in handling of the mappings as ranges instead of individual values which are well over in ~4Bn+.

During the conversion process, we can iterate over each mapping, determining the intersection between the current value ranges (starting with seeds) and the conversion ranges specified in the (subsequent) maps.

If a mapping applies to a particular range, we can transform it accordingly; otherwise, the range remains unchanged.

💡 This approach efficiently reduces the computational load by avoiding the need to process each individual value, instead working with batches of values encapsulated within ranges.

After processing all the mappings, we can get a final set of location ranges, post which we can find the lowest possible location number by selecting the minimum lower bound from these final location ranges.

Here’s the final code:

# --- Day 5: If You Give A Seed A Fertilizer ---

# --- Part Two ---

class AlmanacProcessor:
    def __init__(self, almanac):
        self.seeds = []
        self.maps = []
        self._parse_input(almanac)

    def _parse_input(self, almanac):
        """Parses the input sections into seeds and maps."""
        self.sections = [block.splitlines() for block in almanac.strip().split("\n\n")]
        self.seeds = [int(i) for i in self.sections[0][0].split()[1:]]
        self.maps = [[list(map(int, line.split())) for line in block[1:]] for block in self.sections[1:]]

    def process_maps(self):
        """Processes each map to convert the ranges according to the almanac."""
        # this will store the lower and upper bounds of each range
        values = [(self.seeds[i], self.seeds[i] + self.seeds[i + 1]) for i in range(0, len(self.seeds), 2)] 

        for map in self.maps:
            next_map = []
            for dest_start, src_start, length in map:
                next_range = []
                for val_low, val_high in values:
                    sorted_bounds = sorted([val_low, val_high, src_start, src_start + length])
                    for low, high in zip(sorted_bounds, sorted_bounds[1:]):
                        if val_low <= low < high <= val_high:
                            if src_start <= low < high <= src_start + length:
                                next_map.append((low - src_start + dest_start, high - src_start + dest_start))
                            else:
                                next_range.append((low, high))
                values = next_range
            values += next_map

        return values

    def find_minimum_location(self, values):
        """Finds the minimum location value."""
        return min(low for low, high in values)
