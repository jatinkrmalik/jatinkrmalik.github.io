Jatin Kumar Malik

Today we will learn about Functions in Javascript. If you are coming from a programming background you will be well versed with the concept. If you don’t, well nothing to worry about. It’s really a simple but very important aspect of Programming.

To define,

A JavaScript function is a block of code designed to perform a particular task.A JavaScript function is executed when “something” invokes it (calls it).

In layman terms,

A JavaScript Function is basically a mini-program written inside our Program which doesn’t execute automatically. We have to call(invoke) it in order to do what it is supposed to do.

Still confused? Let’s see an example to understand it in a better way.

I m sure you guys must have a Television (TV) at your home. So, to switch on the TV you press the Power button on the remote, right? So what it does is, when you press the Power button, it invokes a specific function (mini-program) to send the Signal to TV via infrared to Power On. Similarly when you press other buttons like Volume+/Volume-/Channel/Channel-, Remote is preconfigured to invoke only feature specific function and send it to TV in form of Signal.

I hope the example made you aware of how functions work. You can also relate it with example of Calculator where every button is assigned to do a task (function).

Let’s see the Syntax of a Function:

function <function_name>(<parameters>)
{
<Statements>;
}
