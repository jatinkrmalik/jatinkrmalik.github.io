How I Built a Privacy-First Offline Speech-to-Text Tool That I Use Every Single Day

Introducing Vocalinux, an open-source, 100% offline voice dictation tool for Linux using Whisper or VOSK, with its architecture, features and install guide.

Jatin Kumar Malik

For years, macOS and Windows users have enjoyed built-in voice dictation. Just speak, and your words appear on screen — no cloud services, no subscriptions, just pure productivity. Linux users? We were left behind.

Until now.

I’m excited to announce Vocalinux v0.5.0-beta, a voice dictation system for Linux that’s 100% offline, privacy-first, and actually works. I’ve been using this tool daily, and it’s transformed how I interact with my computer.

Updated March 2026 — now at v0.9.0-beta.

See the latest features on GitHub!

Finally, Voice Dictation That Works on Linux!

The Problem

Voice dictation on Linux has historically been a fragmented experience:

  • Janky solutions: Some tools only work in specific apps or require complex setup
  • Cloud dependence: Many services send your voice data to servers, raising privacy concerns
  • Poor integration: Desktop shortcuts and system tray integration were often missing
  • Limited offline support: Most solutions required an active internet connection

As someone who spends hours typing every day, I wanted something better. Something that worked everywhere: terminals, browsers, IDEs, email clients, anywhere I could type, I wanted to dictate.

What Makes Vocalinux Great

1. True 100% Offline Operation

All speech recognition happens on your machine. Your voice data never leaves your computer. No cloud services, no internet required after installation, complete privacy guaranteed.

This isn’t just a privacy feature, it means Vocalinux works even when you’re offline. Perfect for coffee shops, flights, or any situation where internet connectivity is spotty.

2. Universal App Support

Vocalinux works with any text input field on your Linux system. Whether you’re typing in:

  • Terminal or shell
  • Web browsers (Chrome, Firefox)
  • IDEs and code editors (VSCode, Neovim, JetBrains)
  • Email clients
  • Office applications
  • Chat apps (Discord, Slack, Telegram)

Just double-tap Ctrl, and start dictating. The text appears exactly where you would have typed it.

3. Multiple Speech Recognition Engines

Vocalinux supports two powerful engines, each with different strengths:

Whisper AI (Default)

  • OpenAI’s state-of-the-art model
  • Highest accuracy available
  • Multiple model sizes (75MB to 3GB)
  • Excellent multi-language support (99+ languages)
  • Best for clear, accurate transcription

VOSK

  • Lightweight and fast
  • ~50MB model size
  • Low memory footprint
  • Perfect for lower-powered systems
  • Great for real-time streaming

You can switch engines on the fly via settings or command line.

4. Modern Native Linux Integration

Vocalinux isn’t just a web app wrapped in Electron. It’s built with:

  • GTK 3 for the native desktop UI
  • System tray icon for quick access
  • GNOME HIG-compliant settings dialog with modern styling
  • Native keyboard shortcuts using double-tap Ctrl (customizable)
  • X11 and Wayland support — we’ve got you covered regardless of your display server

5. Smart Installation

Installing Vocalinux is incredibly simple:

curl -fsSL raw.githubusercontent.com/jatinkrmalik/vocalinux/main/install.sh \
  -o /tmp/vl.sh && bash /tmp/vl.sh --interactive

That’s it.

The installer:

  • Detects your Linux distribution
  • Installs system dependencies
  • Downloads the appropriate speech recognition models
  • Sets up desktop integration
  • Adds Vocalinux to your PATH

The interactive mode even detects your GPU and suggests the optimal Whisper model size based on your hardware.

Core Components

1. Recognition Manager

  • Multi-threaded audio capture (PyAudio/PortAudio)
  • Voice Activity Detection (VAD) for efficient processing
  • Dual engine support: Whisper AI (accuracy) and VOSK (speed)
  • Real-time transcription with minimal latency
  • Automatic model loading and management

2. Text Injection Layer

  • Cross-platform text injection supporting both X11 and Wayland
  • X11 Backend: Uses XTest extension for native keyboard simulation
  • Wayland Backend: Leverages wtype (Wayland native) with xdotool fallback for XWayland
  • Runtime compositor support detection
  • Focus-aware injection into active window

3. Keyboard Shortcut System

  • evdev Backend: Direct /dev/input/event* device access (works on Wayland)
  • pynput Backend: Cross-platform X11 event monitoring
  • Configurable double-tap shortcuts (default: ctrl+ctrl)
  • Time window detection (500ms configurable)
  • Automatic backend selection based on environment

4. GTK 3 Native UI

  • System tray integration with AppIndicator
  • GNOME HIG-compliant settings dialog
  • Modern, accessible interface components
  • Real-time configuration changes
  • Logging viewer for debugging

Threading Model

Main Thread (GTK Event Loop)
│
├─ Audio Capture Thread (Continuous)

│  ├─ Audio buffer (FIFO queue)
│  └─ Voice Activity Detection
│
├─ Recognition Thread (On-demand)
│  ├─ Whisper/VOSK inference
│  ├─ Result post-processing
│  └─ Text injection queue
│
└─ Keyboard Monitoring Thread (Continuous)
   ├─ evdev/pynput event loop
   └─ Double-tap detection logic

This multi-threaded architecture ensures:

  • Low latency: Audio capture and recognition run in parallel
  • Responsiveness: UI never blocks on speech processing
  • Reliability: Isolated threads prevent cascading failures

Performance Optimizations

  1. Voice Activity Detection: Only processes audio when speech is detected
  2. Model Caching: Speech recognition models loaded once at startup
  3. Buffered I/O: Efficient audio stream handling with thread-safe queues
  4. Lazy Loading: GTK components loaded only after dependency checks
  5. GPU Acceleration: Whisper supports CUDA for NVIDIA GPUs

Why Open Source?

Vocalinux is released under GPL-3.0. Why?

  1. Transparency: You can see exactly what the code does
  2. Privacy: No hidden telemetry or data collection
  3. Community: Anyone can contribute, fork, or improve the project
  4. Sustainability: Open source projects don’t disappear when companies lose interest

I believe voice dictation should be a fundamental tool available to everyone, not a feature locked behind expensive software subscriptions.
